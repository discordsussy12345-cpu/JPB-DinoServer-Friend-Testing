# DinoServer 1.2.19 — Friend Testing

Portable Windows test package for Jurassic Park Builder. Each tester runs their own extracted copy on their Windows PC.

**[Download the testing ZIP](https://github.com/discordsussy12345-cpu/JPB-DinoServer-Friend-Testing/releases/tag/v1.2.19-friend-test)**

Read **[START-HERE.md](START-HERE.md)** before launching, then use **[TEST-CHECKLIST.md](TEST-CHECKLIST.md)** to report results.

## What is included

- Portable Windows DinoServer with its runtime.
- Signed Android game APK for testing immediate paid card-pack debit (SDK26, 32-bit ARM).
- Android and iOS cache download controls; caches download separately.
- A one-time **100,000 Bucks and 1,000,000 XP (displayed level 30)** allowance after a new native park saves and the game reconnects.
- Optional Android/iPad cross-save linking, one device playing the park at a time.

## Quick start

1. Extract the entire ZIP into a new folder. Stop any other DinoServer.
2. Run `DinoServer/DinoServer.exe` and install the matching cache from Cache Delivery.
3. Select the matching platform, configure game routing to your PC's displayed LAN address, and start the server.
4. Play as guest and let the game create and save its park. Fully close and reopen the game to apply the test allowance.

Use a fresh test park. Do not import a personal park into this test. No personal saves or developer device links are included. The latest personal-park restoration fix is not included in this previously packaged test build.

Automatic production updates are disabled. This repository does not publish to the production updater. Physical iPad gameplay and timer behavior still need tester verification. No mobile controller APK or iOS game installer is included.

Keep failure logs and screenshots and send them privately to the project owner; logs may include device identifiers. Do not post saves or logs publicly.
