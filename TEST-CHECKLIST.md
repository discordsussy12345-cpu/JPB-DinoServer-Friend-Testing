# Friend test checklist

Record device/emulator, selected server platform, and pass/fail for each check.

1. Initial login: native park loads without a crash at Sending critical messages.
   Complete date of birth if prompted; close and reopen after the first save.
2. Allowance: displayed level 30, 100,000 Bucks, 1,000,000 XP; no broken park.
3. Paid pack: Buy deducts 200 immediately, BEFORE Tap to open. A no-Bucks pack
   leaves 99,800 from 100,000. A 16-Bucks reward leaves 99,816. Compensation for
   duplicate dinosaurs adds its own amount after the 200 charge. Other gameplay
   rewards can change these example balances; record your actual before/after.
4. Restart: fully close the game and stop/start the server. The latest balance
   and level remain; no refill, reset to level 1 or duplicated welcome/claims.
5. Timers: note remaining battle/dinosaur timer, leave/reopen and compare it.
   This test is investigating timers; it does not promise every timer bug fixed.
6. Optional Android/iPad sharing: link the second device to the same park;
   confirm matching progress/Bucks after switching. Concurrent login must be
   refused. No extra allowance or fresh park should appear on the second device.
7. Language: Guest Saves, cross-save and cache controls follow language changes.

For a failure, keep the exact time, before/after balance, screenshot and this
test folder's server/logs/jpb_current_*.log. Share only with the project owner;
logs and guest saves can contain device identifiers. Do not delete the save or
recovery/lock databases to work around a failure.
